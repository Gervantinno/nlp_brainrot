# NLP Corpus Viewer

Веб-приложение на React для поиска и просмотра лингвистических данных корпуса.

## Возможности

- **Поиск** — поиск слов по канонической форме, базовой форме или любой флексии
- **Карточки слов** — просмотр форм, значения, примеров использования и типа слова
- **Подсветка** — найденные слова подсвечиваются в примерах
- **Задержка поиска** — 300 мс для плавного ввода

## Технологии

- React 19 с TypeScript
- Vite (инструмент сборки)
- CSS (стили, изолированные по компонентам)

## Формат данных

Приложение загружает данные из CSV-файла `public/final_corpus.csv`.

**Формат:** CSV с разделителем-запятой, поля в кавычках поддерживают запятые внутри.

| Колонка | Описание |
|---------|----------|
| canonical | Каноническая форма слова |
| word | Базовая форма слова |
| forms | Флексии (разделитель ` / `) |
| pos | Часть речи (сущ., прил., имя и т.д.) |
| doc_freq | Частота в документах |
| mean_surprisal | Среднее значение surprisal (информационная неожиданность) |
| examples | Примеры использования (разделитель ` \|\|\| `) |
| meaning | Значение/определение слова |
| kind | Тип слова (slang, ru_dict, lat и т.д.) |

### Пример CSV

```csv
canonical,forms,pos,doc_freq,mean_surprisal,examples,meaning,kind
брейнрот,браинрот / бреинрот / брейнрота,сущ.,191,34.76,"Пример 1 \|\|\| Пример 2",значение,slang
```

## Требования к данным

- **Обязательные поля:** `canonical`, `word`, `pos` должны быть заполнены
- **Пустые строки:** игнорируются
- **Неполные строки:** игнорируются (если не хватает обязательных полей)

## Добавление новых данных

1. Поместите CSV-файл в `public/` (например, `final_corpus.csv`)
2. Обновите имя файла в `src/data/words.ts`:
   ```typescript
   const response = await fetch('final_corpus.csv');
   ```
3. Перезапустите сервер разработки
