# NLP Corpus Viewer

Веб-приложение на React для поиска и просмотра лингвистических данных корпуса.

## Возможности

- **Поиск** — поиск слов по канонической форме, базовой форме или любой флексии
- **Карточки слов** — просмотр форм, значения и примеров использования
- **Подсветка** — найденные формы слов подсвечиваются в примерах
- **Задержка поиска** — 300 мс для плавного ввода

## Технологии

- React 19 с TypeScript
- Vite (инструмент сборки)
- CSS (стили, изолированные по компонентам)

## Начало работы

### Установка зависимостей

```bash
npm install
```

### Запуск сервера разработки

```bash
npm run dev
```

### Сборка для продакшена

```bash
npm run build
```


## Формат данных

Приложение загружает данные корпуса из CSV-файла с разделителем `;`:

| Колонка | Описание |
|---------|----------|
| canonical | Каноническая форма слова |
| word | Базовая форма слова |
| forms | Флексии (разделитель ` / `) |
| pos | Часть речи |
| doc_freq | Частота в документах |
| mean_surprisal | Среднее значение surprisal |
| examples | Примеры использования (разделитель ` \|\|\| `) |
| meaning | Значение/определение слова |

## Добавление новых данных

1. Поместите CSV-файл в корень проекта
2. Обновите путь к файлу в `src/data/words.ts`
3. Перезапустите сервер разработки
